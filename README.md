# AcmeNet Customer Support Bot

This project is a Databricks learning portfolio that implements a lightweight RAG-style customer support workflow for a fictional internet provider.

The goal is to learn and demonstrate Databricks notebooks, Spark DataFrames, Delta Tables, SQL, Bronze/Silver/Gold architecture, retrieval, grounded answers, and chatbot interaction logging.

## Workflow

AcmeNet support documents
→ Bronze Delta Table
→ Silver searchable chunks
→ Basic retrieval
→ Grounded answer
→ Gold interaction log
→ SQL analytics

## What I learned

- How to work with Databricks notebooks
- How to create Spark DataFrames
- How to save Delta Tables
- How Bronze/Silver/Gold architecture works
- How basic retrieval works
- How grounded answers reduce hallucination risk
- How to log chatbot interactions for debugging and observability
